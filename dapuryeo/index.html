직접 눌러 볼 수 있는 것

  • 다뿌려 — 기사 체크를 풀고 켜면 「선택 기사 글 만들기 (N)」과 진행 숫자가 같이 움직입니다. 주제 밖 기사는 아예 고를 수 없습니다
  • 다뿌려 — 만들어진 글의 [복사], 본문 수정 시 글자수, 「원문 ↗」로 실제 기사 확인
  • 후킹자판기 — 상품 선택 → 뽑기 → 3줄 문구 · 남은 횟수 차감 · 복사
  • 관리자 표 — 필터·정렬·페이지 이동·건수, 「주소 확인」 드롭다운, 상세 펼침, 미리보기, 연락처 열람 기록
  • 발행 랜딩 — 신청 폼의 동의 3개 분리, 요금표, 법정 표시

아직 안 되는 것 — 미리 말씀드립니다

  • 실제 SNS 게시 — 다음 단계입니다. 총판 계정 연동([허용] 클릭)과 Meta 앱이 있어야 나갑니다. 지금은 게시 직전(예약안)까지입니다
  • 「오늘 콘텐츠 자동 만들기」 버튼 — 이 검토용 주소에는 서버가 없어 버튼이 직접 돌지 않습니다. 실행은 별도로 돌려 매일 결과를 올립니다(누르면 그 사실을 알려 줍니다)
  • 로그인 — 모양만 있습니다. 계정 없이 들어갑니다
