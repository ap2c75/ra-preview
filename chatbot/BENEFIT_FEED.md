# 고객 공개 혜택 원장

`api/benefits.json`은 고객에게 공개할 수 있는 혜택만 담습니다. 총판 판매 수수료와 브로씨앤씨 몫은 입력할 수 없으며 검증기가 해당 필드와 문구를 차단합니다.

운영 담당자가 상품 코드별 혜택 종류, 고객 표시 문구, 적용 조건, 원장 위치, 확인 시각과 유효기간을 입력하고 `status`를 `reviewed`로 바꿔야 추천 순위에 반영됩니다. 유효기간이 지나거나 검토자가 비어 있으면 전체 혜택 원장을 무시하고 기존 월요금·공개 할인 정보만 사용합니다.

지원금 액수가 없는 현재 상태에서는 챗봇이 “지원금이 가장 좋은 상품”이라고 단정하지 않습니다. 실제 원장이 들어오면 같은 카테고리에서 브랜드별 후보를 먼저 만들고, 각 브랜드 안에서 확인된 고객 지원 혜택이 큰 상품을 선택합니다.
